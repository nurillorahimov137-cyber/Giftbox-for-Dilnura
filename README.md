# Dilnura — My Princess ♡

A cinematic, interactive 3D story made as a little digital gift for Dilnura.

## Features
- Five chapters with a guided romantic story
- Real-time 3D starfield, glowing heart, floating lights and a stylized rose
- Responsive layout for phones and desktops
- Optional ambient tones (starts only after the visitor taps the sound control)
- Reduced-motion-friendly styling and graceful 3D fallback

## Run locally
Open `index.html` in a modern browser with an internet connection. Three.js and fonts are loaded from CDNs.

## Deploy
The included GitHub Actions workflow publishes the site to GitHub Pages whenever changes are pushed to `main`.

If Pages has not been enabled for this repository yet, open **Settings → Pages** and choose **GitHub Actions** as the build and deployment source.
